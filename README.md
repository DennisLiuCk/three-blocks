# three-blocks

一款決策型小遊戲的雛型:每回合從三個方塊中選一個疊上塔,五回合,最多容許失敗兩次。目標不是打敗其他玩家,而是挑戰規則本身——機率存在,但玩家可以影響機率,所以失敗感覺像自己判斷錯誤,而不是運氣不好。塔的高度是進度,塔的傾斜是還能承受幾次失敗。

設計方向與決策記錄見 [`docs/design-brief.md`](docs/design-brief.md)。

## 技術

- Godot 4.x + GDScript
- `rules/`:規則層,不依賴場景樹,規則與呈現分離但放在同一個專案裡。
- `presentation/`:呈現層,場景與視覺,訂閱規則層的 signal 來播動畫、更新畫面。

## 執行

用 Godot 4(建議 4.3 以上)開啟本專案資料夾,執行 `presentation/main.tscn`(已設為預設主場景)。

> 目前的呈現只是佔位視覺(用色塊的大小與顏色表示風險/報酬),尚未在 Godot 編輯器中實際開啟驗證過,請以此為起點在編輯器中檢查、調整。
